# Alexandre-Leboeuf OpenGOAL Mod Source

Custom mod source for the OpenGOAL Mod Launcher.

## How to add this source

In the OpenGOAL Mod Launcher, go to **Settings → Mods → Add Source** and paste:

```
https://raw.githubusercontent.com/Alexandre-Leboeuf/OpenGOAL-Mods-Source/main/mods.json
```

## Available mods

### Jak 3 Better Forms Mod
Dark Jak and Light Jak never auto-de-transform. Dark Jak can use all weapons. Jetboard usable in both forms. Crouch and rolls work in both forms. DragonBall-style 4x speed and jump multipliers.
